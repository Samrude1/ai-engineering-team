# 📈 Trading Simulation Platform

An automated, full-stack Python application generated end-to-end by the **AI Engineering Team**.

## Features
- **Account & Cash Ledger**: Real-time deposit/withdrawal balance management with overdraw protection.
- **Stock Execution Engine**: Buy and sell equity shares with real-time portfolio valuation.
- **Auditing & History**: Immutable transaction logs with incremental sequence IDs.
- **Interactive UI**: Gradio 5+ visual control dashboard with real-time feedback.
- **Unit Test Suite**: 100% test coverage with `unittest`.

## Quickstart
1. Install dependencies:
   ```bash
   pip install gradio
   ```
2. Run unit tests:
   ```bash
   python -m unittest test_accounts.py
   ```
3. Launch UI:
   ```bash
   python app.py
   ```
